# WhatsApp Information Extractor

## About the Project
WhatsApp Information Extractor is a Python-based web application built with Streamlit. It helps users identify useful information from exported WhatsApp chat text files, including job vacancies, business leads, advertisements, phone numbers, and website links.

## Features
- **Job Vacancy Detection:** Finds messages containing job and recruitment keywords.
- **Business Lead Detection:** Identifies messages related to customers, clients, projects, and business opportunities.
- **Advertisement Detection:** Finds promotional offers, discounts, and admission announcements.
- **Phone Number Extraction:** Identifies phone numbers in chat messages.
- **Link Extraction:** Collects website links from messages.
- **Custom Keywords:** Allows users to search for additional terms, such as scholarships, tenders, and events.
- **Excel Export:** Downloads extracted results as an Excel file.
- **Web Interface:** Provides a simple interface for uploading and processing chat exports.

## Technologies Used
- Python
- Streamlit
- Pandas
- Regular Expressions (Regex)
- OpenPyXL

## How to Use
1. Export a WhatsApp chat as a `.txt` file.
2. Open the web application.
3. Upload the exported text file.
4. Enter additional keywords if required.
5. Review the extracted messages, phone numbers, and links.
6. Download the results as an Excel file.

## Project Type
Python | Data Extraction | Text Processing | Web Application

## Important Note
This application currently processes uploaded WhatsApp `.txt` chat exports. It does not automatically monitor live WhatsApp messages. Use only chat data you have permission to process.
